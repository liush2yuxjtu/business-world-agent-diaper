## 九页的任务与后续路径

| 页面 | 核心任务 | 下一步 |
| --- | --- | --- |
| 经营总览 | 查看人工记录、数据准备情况和真正保存的工作成果 | 商业关系 / 内容提纲 / 直播任务 / 情景 |
| 消费者洞察（Persona Studio） | 先写研究问题；真实画像不足时不编造人群 | 带着研究背景进入内容策略 |
| 业务数据（World Builder） | 查看指标、来源、关联因子与历史情景 | 带着指标进入实验 |
| 内容策略 | 编辑内容提纲、确认保存、继续发布计划草稿 | 带着内容背景进入直播 |
| 直播运营 | 准备开播、关联商品、整理复盘任务 | 商品分析 |
| 投放优化 | 记录投放建议，不直接改动预算 | 预填广告效率实验 |
| 商品分析 | 提出商品问题，明确 SKU / 库存需要独立证据 | 人群 / 投放 / 转化实验 |
| 情景实验 | 基于固定基准比较假设，结果与真实记录分开 | 选定结果进入报告 |
| 经营报告 | 固定证据、独立人工备注、明确分享与导出 | 返回总览复盘 |

所有主入口保留确认、校验和持久化反馈。所有页面都有主任务、一个经营流程导航和来源状态。桌面与手机使用相同真实组件。

## 流程修复

跨页 handoff 携带来源页面和来源名称。新建草稿继承上下文，并按人群 / 内容 / 直播 / 投放 / 商品预填不同的可编辑字段。保存仍要求明确确认。

路由由替换历史改为真实浏览器历史；Back、Forward、reload 恢复对应页面的上下文。清除背景同样在刷新后生效。上下文只是页面历史中的显示数据，不是额外的业务数据库。

## 不得越过的产品边界

人工录入不是已核验观测；示例必须主动展开且清楚标记；情景是未校准敏感性计算，不是预测。无历史序列时不伪造经营趋势，无平台连接时不伪造“已连接”。

首次共享读取失败继续保持 unknown；新主按钮也不能绕过这个边界打开空白替换表单。没有静默 fallback 到本地记录；同一账户 UI 与实际 Agent 共用 owner-scoped 服务与版本检查。公开分享仅为用户明确同意的不可撤销只读副本，不能访问原工作区。
