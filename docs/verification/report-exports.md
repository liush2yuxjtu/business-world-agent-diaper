# PDF / PPT 报告导出验收

报告中心新增 PDF 与 PPT 按钮。两种格式均从当前浏览器拥有的、精确 ID 与 revision 的已保存报告生成，共用 reportSections 内容，不读取当前经营基线覆盖历史。未保存的备注必须先处理；版本不一致拒绝导出并提示重新读取。

PDF 使用 PDFKit 和随仓库提供的 Noto Sans SC 静态字重字体，运行时嵌入字形子集。PPTX 使用 PptxGenJS 生成可编辑文本。两者保留报告标题、读者、周期、自动摘要、经营指标、人工备注和来源时间。长中文文本自动分页；具体字体来源、许可证和转换方式见 lib/business-world/fonts/README.md。

本地验证：
- 12 项业务边界、固定快照和无损折行测试，类型检查与生产构建通过。
- 3,536 字人工备注实际生成 3 页 PDF、12 页 PPT。解包/文字提取核对全段备注、末尾标记、报告 ID 与版本，经过 PDFium 及 LibreOffice 实际渲染检查中文可见、备注分页和来源页。
- 内置浏览器对已有报告 4a6f2986-2f06-4b7a-80f0-fb4e78f0e158 revision 2 点击导出；在下载目录检查实际文件，不用“下载已开始”提示替代文件证据。
- 接口以 409 拒绝过期版本、400 拒绝无效格式、404 拒绝缺少浏览器报告标识的读取。导出不修改报告或经营基线。
- 生产构建的资源追踪包含中文字体和 PDFKit 字体资源；精确线上预览还须实际下载确认，不能仅凭构建成功判定通过。

只读分享、邮件草稿、跨页工作流、Agent 同源报告操作与完整 HTML/MD 配对审计仍未完成。
