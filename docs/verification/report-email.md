# 报告邮件草稿验证

报告中心新增“发送到邮箱”入口：从选中报告固定版本生成收件人、中文主题与正文编辑器，保留来源、合成数据说明、独立人工备注、报告编号和版本。下载标准 MIME `.eml` 草稿，用户在邮件软件检查后发送；页面不连接邮件服务，也不声称已经发送。草稿仅在当前页编辑，页面说明下载留存以及关闭会重置。

2026-09-21 本地验证：14 项测试、类型检查、Next 生产构建通过。测试覆盖历史快照与人工备注不受邮件编辑影响、长 Unicode MIME 内容无损、CRLF 头注入拒绝、单一收件邮箱限制。

真实内置浏览器读取已保存报告 `4a6f2986-2f06-4b7a-80f0-fb4e78f0e158` 第 2 版，打开编辑器，填写保留示例地址 `review@example.com` 并下载。实际 Downloads 文件 1412 字节，用 Python 标准 `email` 解析器验证中文主题、收件人、原人工备注、revision 和 `X-Unsent: 1` 全部通过。未向任何地址发送邮件。

此项实现 canonical HTML/MD 邮件操作的草稿阶段。PDF/PPT 附件需用户在邮件软件自行添加，页面有明确说明。只读分享、跨页草稿、Agent 同源操作及完整意图/开发审计仍未完成，不能据此认定整个报告分发或完整产品已通过。
