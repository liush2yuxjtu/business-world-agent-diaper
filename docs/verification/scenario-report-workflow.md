# 实验到报告工作流

实验历史的已保存结果新增“发送到报告”。报告创建表单带入情景 ID 与假设预览；服务端重新读取该记录的完整历史基线和结果，禁止用当前经营状态替代。生成后保存关联情景、提供返回来源实验的链接，文本、邮件草稿、PDF、PPT 共用固定的关联内容。

历史情景表只保存业务基线，没有保存完整来源观测时间；报告明确该限制，asOf 保持 null，不拿实验创建时间冒充原始观测时间。推演结果单独呈现，不覆盖经营基线，也不修改当前业务数据。不存在或无效情景不会退回生成普通报告。
