# Business investigation

1. Restate the decision or anomaly being investigated.
2. Read the narrowest Business World tool that can answer it. Use `business_world_snapshot` only when the question spans domains.
3. Record provenance before interpreting values: source mode, source label, observation time, and update time.
4. Write 1-3 falsifiable hypotheses.
5. Test each hypothesis against the available evidence. Missing evidence stays missing.
6. Delegate a compact evidence packet to `diagnostician` when cross-domain reasoning is needed.
7. Report:
   - verified/persisted evidence;
   - simulated values;
   - inference or scenario results;
   - unresolved questions;
   - safest next test.
8. Never mutate shared state or an external platform as part of investigation.
