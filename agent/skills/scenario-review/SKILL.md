# Scenario review

Before recommending a scenario:

1. Read the current baseline and provenance.
2. State exactly which lever changes and by how much.
3. Treat `business_scenario_experiment` as a transparent mathematical model, never a market forecast.
4. Compare baseline and modeled values explicitly.
5. Check operational constraints that the model does not encode, including inventory, fulfillment, brand, budget, and measurement quality.
6. Use `scenario-reviewer` for an independent critique when the scenario would influence a meaningful decision.
7. Keep external execution out of scope unless a separate approval-gated tool exists and the user approves it.
